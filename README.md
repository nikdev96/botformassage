# Nova Chaloklum Health Massage Telegram Bot

Двуязычный Telegram-бот (RU/EN) для записи на услуги массажа и спа салона Nova Chaloklum Health Massage.

## 🚀 Возможности

- **Двуязычный интерфейс**: Русский и английский языки
- **4 категории услуг**: Массаж, Spa, Воск, Ногти
- **Гибкие опции**: Выбор длительности для каждой услуги
- **Полный процесс записи**: Inline-календарь → Временные слоты → Имя → Телефон → Подтверждение
- **Ограничение бронирования**: Запись не более чем на 14 дней вперед
- **Умные временные слоты**: Автоматическая фильтрация прошедшего времени с учетом часового пояса
- **Уведомления администратора**: Автоматические уведомления о новых записях
- **AI ассистент** (опционально): Интеграция с ChatGPT для ответов на вопросы клиентов
- **Постоянная клавиатура**: Reply-клавиатура с категориями услуг
- **Офлайн-тестирование**: Проверка работоспособности без Telegram

## 📋 Установка и настройка

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Настройка окружения
```bash
cp .env.example .env
# Отредактируйте .env файл с реальными данными:
# - BOT_TOKEN: токен вашего Telegram бота (@BotFather)
# - ADMIN_CHAT_ID: ID чата для уведомлений
# - TZ: часовой пояс (по умолчанию Asia/Bangkok)
# - OPENAI_API_KEY: API ключ OpenAI (опционально, для ChatGPT)
# - FEATURE_CHATGPT: 1 для включения AI ассистента, 0 для отключения
```

**⚠️ ВАЖНО**: 
- **НИКОГДА** не коммитьте файл `.env` в git
- **НИКОГДА** не делитесь BOT_TOKEN публично
- Файл `.env` уже добавлен в `.gitignore`

### 3. Запуск бота
```bash
python main.py
```

## 🤖 AI Ассистент (ChatGPT)

### Настройка
1. Получите API ключ на [OpenAI Platform](https://platform.openai.com/)
2. Добавьте ключ в .env файл: `OPENAI_API_KEY=your_api_key_here`
3. Включите функцию: `FEATURE_CHATGPT=1`

### Использование
- **Команда**: `/ai`
- **Модель**: GPT-4o-mini (быстрая и экономичная)
- **Контекст**: Специализирован на массаже, спа-процедурах, здоровье и велнесе
- **Автолокализация**: Отвечает на языке пользователя

### Безопасность
- Функция легко отключается установкой `FEATURE_CHATGPT=0`
- При отсутствии ключа показывается сообщение "ИИ временно недоступен"
- AI доступен только при включенной функции через команду `/ai`

## 🛠 Обновление каталога услуг

Каталог услуг теперь находится в файле `models.py` в переменной `SERVICE_CATALOG`.

### Структура услуги:
```python

    key="service_key",           # Уникальный ключ
    title_ru="Название на русском",
    title_en="Title in English",
    variants=[                   # Варианты длительности/цен
        ServiceVariant(60, 400), # 60 минут за 400 THB
        ServiceVariant(90, 600)  # 90 минут за 600 THB
    ],
    note="Дополнительные заметки (опционально)"
)
```

## 📅 Календарное бронирование

### Рабочие часы
Настройка рабочего времени находится в переменной `WORKING_HOURS` в файле `config.py`:
```python
WORKING_HOURS = {
    0: ("10:00", "22:00"),  # Понедельник
    1: ("10:00", "22:00"),  # Вторник
    # ... остальные дни
    6: ("10:00", "20:00"),  # Воскресенье
}
```

### Конфигурация календаря
- `SLOT_STEP_MIN = 30` - шаг временных слотов в минутах
- `MAX_DAYS_AHEAD = 14` - максимум дней вперед для бронирования (заменяет MAX_MONTHS_AHEAD)
- `TZ = "Asia/Bangkok"` - часовой пояс (настраивается в .env)
- **Учет таймзоны**: Прошедшие слоты для текущего дня автоматически скрываются с буфером 30 минут

### Система резерваций
- В памяти храним занятые слоты в `RESERVATIONS`
- При подтверждении бронирования слот фиксируется автоматически
- Учитываются рабочие часы и минимальные интервалы

## 🔧 Технические детали

### Используемые технологии:
- **aiogram 3.13.1** - Фреймворк для Telegram ботов
- **python-dotenv 1.0.1** - Управление переменными окружения
- **openai >=1.40.0** - Интеграция с ChatGPT (опционально)

### Безопасность и разметка:
- **Унифицированный Markdown**: Весь бот использует ParseMode.MARKDOWN как дефолт
- **Безопасное экранирование**: Пользовательские данные (имя, телефон) автоматически экранируются перед отправкой
- **Улучшенная валидация**: Телефонные номера проверяются регулярными выражениями с поддержкой различных форматов

### Ключевые переменные состояния FSM:
- `service_key` - Ключ выбранной услуги
- `duration` - Выбранная длительность
- `date_str` - Дата в формате ДД.ММ.ГГГГ (для отображения пользователю)
- `date_iso` - Дата в формате YYYY-MM-DD (для внутренних расчетов)
- `time_str` - Время в формате ЧЧ:ММ
- `client_name` - Имя клиента
- `client_phone` - Телефон клиента

### Хранение языков пользователей:
Языки пользователей хранятся в памяти в словаре `user_languages`. 
Для продакшена рекомендуется использовать базу данных.
