# Nova Chaloklum Health Massage Telegram Bot

Двуязычный Telegram-бот (RU/EN) для записи на услуги массажа и спа салона Nova Chaloklum Health Massage.

## 🚀 Возможности

- **Двуязычный интерфейс**: Русский и английский языки
- **4 категории услуг**: Массаж, Spa, Воск, Ногти
- **Гибкие опции**: Выбор длительности для каждой услуги
- **Полный процесс записи**: Inline-календарь → Временные слоты → Имя → Телефон → Подтверждение
- **Ограничение бронирования**: Запись не более чем на 14 дней вперед
- **Умные временные слоты**: Автоматическая фильтрация прошедшего времени с учетом часового пояса
- **Уведомления администратора**: Автоматические уведомления о новых записях
- **AI ассистент** (опционально): Интеграция с ChatGPT для ответов на вопросы клиентов
- **AI помощник записи**: Умное распознавание запросов на бронирование и автоматическое оформление записей
- **Автоматическое определение намерений**: Система распознает фразы типа "можешь записать на массаж?" и активирует AI записи
- **Постоянная клавиатура**: Reply-клавиатура с категориями услуг
- **Офлайн-тестирование**: Проверка работоспособности без Telegram

## 📋 Установка и настройка

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Настройка окружения
```bash
cp .env.example .env
# Отредактируйте .env файл с реальными данными:
# - BOT_TOKEN: токен вашего Telegram бота (@BotFather)
# - ADMIN_CHAT_ID: ID чата для уведомлений
# - TZ: часовой пояс (по умолчанию Asia/Bangkok)
# - OPENAI_API_KEY: API ключ OpenAI (опционально, для ChatGPT)
# - FEATURE_CHATGPT: 1 для включения AI ассистента, 0 для отключения
# - FEATURE_AI_BOOKING: 1 для включения AI помощника записи
# - WEBHOOK_PORT: порт для webhook сервера (по умолчанию 8080)
```

- **НИКОГДА** не делитесь BOT_TOKEN публично
- Файл `.env` уже добавлен в `.gitignore`

## 🤖 AI Ассистент (ChatGPT)

### Настройка
1. Получите API ключ на [OpenAI Platform](https://platform.openai.com/)
2. Добавьте ключ в .env файл: `OPENAI_API_KEY=your_api_key_here`
3. Включите функцию: `FEATURE_CHATGPT=1`

### Использование
- **ChatGPT**: Любое текстовое сообщение автоматически отправляется в ChatGPT для ответа
- **AI Booking**: Фразы с ключевыми словами (записать, забронировать, book, appointment) активируют AI помощника записи
- **Модель**: GPT-4o-mini (быстрая и экономичная)
- **Контекст**: Специализирован на массаже, спа-процедурах, здоровье и велнесе
- **Автолокализация**: Отвечает на языке пользователя

#### Примеры активации AI записи:
- "можешь записать на массаж?"
- "хочу забронировать спа процедуру"
- "book me a massage"
- "запиши меня на завтра"

### Безопасность
- Функция легко отключается установкой `FEATURE_CHATGPT=0`
- При отсутствии ключа показывается сообщение "ИИ временно недоступен"
- AI доступен только при включенной функции через команду `/ai`

## 📅 Календарное бронирование

### Рабочие часы
Настройка рабочего времени находится в переменной `WORKING_HOURS` в файле `config.py`:
```python
WORKING_HOURS = {
    0: ("10:00", "22:00"),  # Понедельник
    1: ("10:00", "22:00"),  # Вторник
    # ... остальные дни
    6: ("10:00", "20:00"),  # Воскресенье
}
```

### Конфигурация календаря
- `SLOT_STEP_MIN = 30` - шаг временных слотов в минутах
- `MAX_DAYS_AHEAD = 14` - максимум дней вперед для бронирования (заменяет MAX_MONTHS_AHEAD)
- `TZ = "Asia/Bangkok"` - часовой пояс (настраивается в .env)
- **Учет таймзоны**: Прошедшие слоты для текущего дня автоматически скрываются с буфером 30 минут

### Система резерваций
- В памяти храним занятые слоты в `RESERVATIONS`
- При подтверждении бронирования слот фиксируется автоматически
- Учитываются рабочие часы и минимальные интервалы

## 🔧 Технические детали

### Используемые технологии:
- **aiogram 3.13.1** - Фреймворк для Telegram ботов
- **python-dotenv 1.0.1** - Управление переменными окружения
- **openai >=1.40.0** - Интеграция с ChatGPT (опционально)

### Безопасность и разметка:
- **Унифицированный Markdown**: Весь бот использует ParseMode.MARKDOWN как дефолт
- **Безопасное экранирование**: Пользовательские данные (имя, телефон) автоматически экранируются перед отправкой
- **Улучшенная валидация**: Телефонные номера проверяются регулярными выражениями с поддержкой различных форматов

### Ключевые переменные состояния FSM:
- `service_key` - Ключ выбранной услуги
- `duration` - Выбранная длительность
- `date_str` - Дата в формате ДД.ММ.ГГГГ (для отображения пользователю)
- `date_iso` - Дата в формате YYYY-MM-DD (для внутренних расчетов)
- `time_str` - Время в формате ЧЧ:ММ
- `client_name` - Имя клиента
- `client_phone` - Телефон клиента

### Хранение языков пользователей:
Языки пользователей хранятся в памяти в словаре `user_languages`. 
Для продакшена рекомендуется использовать базу данных.


## 🔧 Новые функции и компоненты

### AI Booking Assistant (`ai_booking.py`)
**Интеллектуальный помощник по записи на основе OpenAI GPT-4o-mini**

Основные функции:
- `get_services_catalog_for_ai()` - Подготавливает каталог услуг для AI
- `ai_extract_booking()` - Извлекает данные записи из естественного языка  
- `normalize_and_validate()` - Нормализует и валидирует данные бронирования

Возможности:
- Понимание естественного языка на русском и английском
- Автоматическое извлечение даты, времени, имени, телефона
- Умная обработка относительных дат ("завтра", "послезавтра")
- Контекстные подсказки при неполных данных
- Дружелюбное взаимодействие для русскоязычных пользователей

### Google Sheets Integration (`google_sheets.py`)
**Интеграция с Google Sheets для хранения записей и проверки занятости**

Ключевые функции:
- `init_sheets()` - Инициализация подключения к Google Sheets
- `fetch_bookings_for_date()` - Получение записей на конкретную дату
- `get_sheets_reservations_for_date()` - Получение занятых временных слотов
- `fetch_due_reminders()` - Поиск записей для отправки напоминаний
- `mark_reminder_sent()` - Отметка отправленных напоминаний
- `ensure_reminder_column()` - Добавление колонки для напоминаний

Возможности:
- Автоматическое создание колонок в таблице
- Кэширование данных для оптимизации производительности
- Обработка различных форматов дат и времени
- Поддержка напоминаний с настраиваемым временем

### Webhook Server (`webhook_server.py`)
**Flask-сервер для приема webhook-уведомлений от внешних систем**

Основные функции:
- `handle_booking_webhook()` - Обработка webhook создания записи
- `write_booking_to_sheets()` - Запись данных в Google Sheets
- `find_booking_row()` - Поиск строки записи по ID
- `health_check()` - Проверка здоровья сервера

Возможности:
- Автоматическая запись в Google Sheets при создании записи
- Валидация входящих webhook-данных
- Обработка ошибок и логирование
- Поддержка различных источников записи (manual, ai)
- **Конфигурация через переменные окружения**: Все настройки (порт, ID таблицы, файл credentials) теперь настраиваются через .env
- **Английские названия в таблице**: Все названия услуг автоматически записываются на английском языке для англоговорящего руководителя

### Reminder System (`reminder_system.py`)
**Система автоматических напоминаний клиентам**

Ключевые функции:
- `ReminderSystem.start()` - Запуск системы напоминаний
- `ReminderSystem.stop()` - Остановка системы
- `ReminderSystem._check_reminders()` - Проверка и отправка напоминаний

Возможности:
- Автоматические напоминания за 2 часа до записи
- Многоязычная поддержка напоминаний
- Предотвращение дублирования отправок
- Настраиваемые интервалы проверки

### Утилиты и валидация (`utils.py`)
**Расширенные функции валидации и форматирования**

Новые функции:
- `escape_md()` - Экранирование Markdown-разметки 
- `safe_text()` - Безопасное форматирование пользовательского ввода
- `is_valid_phone()` - Улучшенная валидация телефонных номеров
- `format_reminder_message()` - Форматирование сообщений напоминаний
- `get_service_by_key()` - Поиск услуги по ключу
- `get_service_variant()` - Поиск варианта услуги по длительности

### Модели данных (`models.py`)
**Структурированные модели для каталога услуг**

Новые классы:
- `Service` - Модель услуги с многоязычными названиями
- `ServiceVariant` - Вариант услуги (длительность + цена)  
- `BookingState` - Состояния FSM для процесса бронирования

Константы:
- `SERVICE_CATALOG` - Полный каталог всех услуг (20 услуг в 4 категориях)
- `SERVICE_CATEGORIES` - Категории услуг для группировки
